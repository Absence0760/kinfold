# project-insurance

## Vision - no changes will be made to this vision

Low to zero monthly payments and have insurance.
Insurance is required however paying for insurance should NOT!

Start with auto insurance then move on the all other types

Will be subscription based depending on your earnings. Submit latest bank statements.
A user will have the option to select where his subscription payment goes.

Everything is public - except PII.

There should be a list of claims, the person submitting a claim needs to provide evidence.
The person submitting the claim will be responsible for blanking out or removing any PII information.
This evidence will determine how legit the claim is.
Will also need an ai model determining legitimacy.
Claims with highest legitimacy score will get filled first. So if we have 10 claims above 90% legitimacy,
each claim will be filled concurrently.

## Insuance will need to be fraud proof.

    - A user should not be able to submit a claim given a quote from a more expensive company and then use a cheaper company.
    - Any form of staging acts
